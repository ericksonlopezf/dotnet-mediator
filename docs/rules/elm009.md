# ELM009: Stream Handler Not Found

| Property | Value |
|---|---|
| **Rule ID** | `ELM009` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types implementing `IStreamRequest<TResponse>` |

---

## 🎯 Rule Description

Emitted when an asynchronous streaming request implementing `IStreamRequest<TResponse>` has no corresponding `IStreamRequestHandler<TRequest, TResponse>` registered in the compilation.

---

## ❌ Violation Example

```csharp
public readonly record struct StreamTelemetryRequest(DateTime From, DateTime To) : IStreamRequest<MetricPoint>;

// Violation: No stream handler found for StreamTelemetryRequest
```

---

## ✅ Compliant Example

```csharp
public sealed class StreamTelemetryHandler : IStreamRequestHandler<StreamTelemetryRequest, MetricPoint>
{
    public async IAsyncEnumerable<MetricPoint> Handle(StreamTelemetryRequest request, [EnumeratorCancellation] CancellationToken cancellationToken)
    {
        yield return new MetricPoint(DateTime.UtcNow, 42.0);
    }
}
```

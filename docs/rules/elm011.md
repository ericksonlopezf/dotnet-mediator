# ELM011: Invalid Stream Handler Signature

| Property | Value |
|---|---|
| **Rule ID** | `ELM011` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types implementing `IStreamRequestHandler` |

---

## 🎯 Rule Description

Stream request handlers must return `IAsyncEnumerable<TResponse>` and accept `(TRequest request, CancellationToken cancellationToken)`. If the signature deviates (e.g. returning `IEnumerable<T>` or `Task<IAsyncEnumerable<T>>`), `ELM011` is emitted.

---

## ❌ Violation Example

```csharp
public sealed class BadStreamHandler : IStreamRequestHandler<FetchLogsRequest, LogEntry>
{
    // Violation: Returns IEnumerable instead of IAsyncEnumerable
    public IEnumerable<LogEntry> Handle(FetchLogsRequest request, CancellationToken cancellationToken) => ...;
}
```

---

## ✅ Compliant Example

```csharp
public sealed class CompliantStreamHandler : IStreamRequestHandler<FetchLogsRequest, LogEntry>
{
    public async IAsyncEnumerable<LogEntry> Handle(FetchLogsRequest request, [EnumeratorCancellation] CancellationToken cancellationToken)
    {
        yield return new LogEntry("Log 1");
    }
}
```

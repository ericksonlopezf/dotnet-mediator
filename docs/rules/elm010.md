# ELM010: Multiple Stream Handlers Found

| Property | Value |
|---|---|
| **Rule ID** | `ELM010` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types implementing `IStreamRequest<TResponse>` |

---

## 🎯 Rule Description

Streaming requests must have exactly one handler producing the asynchronous stream sequence. If multiple implementations of `IStreamRequestHandler<TRequest, TResponse>` are discovered, compilation fails with `ELM010`.

---

## ❌ Violation Example

```csharp
public readonly record struct StreamEventsRequest : IStreamRequest<EventItem>;

public sealed class DatabaseStreamHandler : IStreamRequestHandler<StreamEventsRequest, EventItem> { ... }
public sealed class KafkaStreamHandler : IStreamRequestHandler<StreamEventsRequest, EventItem> { ... } // Violation
```

---

## ✅ Compliant Example

Consolidate streaming logic or differentiate request types:

```csharp
public sealed class StreamEventsHandler : IStreamRequestHandler<StreamEventsRequest, EventItem>
{
    public async IAsyncEnumerable<EventItem> Handle(StreamEventsRequest request, [EnumeratorCancellation] CancellationToken cancellationToken)
    {
        yield return new EventItem("Sample");
    }
}
```
